# Matrix Screensaver for Linux (Multi-Monitor)
Note: Currently tested on Debian-based distributions (Ubuntu, Linux Mint). The auto-installer relies on apt

A non professional, multi-monitor matrix screensaver for Linux (X11). 
It features optional smooth fade-to-black and automatic shutdown.

## Features
- 🖥️ **Multi-Monitor Support**: Automatically detects and fills all connected screens.
- 🌈 **True Colors**: Uses `cmatrix | lolcat` for beautiful rainbow effects.
- ⚙️ **Auto-Installer**: Checks and installs missing dependencies automatically.
- 🌙 **Smart Shutdown**: Optionally fades the screen to black, hides the mouse, and powers off the PC.
- 🛑 **Clean Exit**: Press `Ctrl+C` to close the screensaver and return to your desktop.

## Installation

Run this command in your terminal:

git clone https://github.com/daddylock/matrix-screensaver.git
cd matrix-screensaver
sudo ./install.sh
